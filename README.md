# The Verdict Room

This was my last group project of Year 12, you play as a judge and decide the convicts fate.
## How To Play

Just Download the latest release and run .exe. Note: Windows only.
## Run in Unity

Click on the blue "<>Code" dropdown and click "download zip".
Unzip the folder and open Unity, click add and locate the unzipped folder.
It should open now.
